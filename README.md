## 🌐 Cube Lab

An interactive 3D Rubik's Cube that works across phones, tablets, and desktops.
Open `index.html` in a browser or serve the repository with any static web server.

- Drag the cube to orbit the view; use the face buttons or `U`, `R`, `F`, `D`, `L`, and `B` keys to turn it.
- Hold `Shift` with a move key for a counter-clockwise turn.
- Shuffle, undo the last turn, or reset the cube. Best solve time is saved in this browser.

The app uses plain HTML, CSS, and JavaScript with no build step or runtime dependencies.
It is installable as a Progressive Web App (PWA) when hosted over HTTPS. The first visit
caches the app shell for offline use. On iPhone, open the HTTPS link in Safari and choose
Share → Add to Home Screen; on a laptop, use the browser's Install app option.
GitHub Actions publishes only the app files to GitHub Pages when changes reach `main`.
